# 산타 선물 대작전

아들과 함께 만든 두 번째 게임입니다. 루돌프 썰매를 타고 하늘에서 내려오는 선물을 받아서, 집 굴뚝으로 배달해요.

## 게임 방법
- 게임은 항상 가로 화면이에요. 세로로 든 폰에서는 화면이 옆으로 누워 나오니 폰을 옆으로 돌려요.
- **왼손**: 화면을 위아래로 문질러 썰매를 움직여요.
- **오른손**: "선물 쏙!" 버튼을 눌러 선물을 떨어뜨려요. 굴뚝 위에 "지금!"이 보일 때 누르면 쏙 들어가요.
- 낙하산을 타고 내려오는 선물을 썰매로 받아야 자루가 채워져요(최대 9개).
- 까만 석탄과 먹구름은 피해요. 하트 3개를 다 잃으면 실패예요.
- 아침이 오기 전에 목표만큼 배달하면 성공. 더 많이 배달하면 별 2개, 3개.
- 12월 1일부터 24일 크리스마스 이브까지, 하루를 성공하면 다음 날이 열려요. 24일에는 큰 크리스마스 트리와 불꽃놀이가 있어요.

## 아들과 같이 바꿔 보기 좋은 곳 (`index.html`)
| 바꾸고 싶은 것 | 찾을 단어 |
|---|---|
| 날마다 빠르기, 목표, 석탄과 먹구름 양 | `function dayCfg` |
| 자루에 넣을 수 있는 선물 수 | `SACK_MAX` |
| 선물 포장 색 | `GIFT_COLORS` |
| 아이들이 하는 말 | `THANKS` |

## 폰에 설치하기
주소: https://sungpyo15-ship-it.github.io/Happy_livestock/santa-game/
- 아이폰(Safari): 공유 → 홈 화면에 추가
- 안드로이드(Chrome): ⋮ → 홈 화면에 추가 / 앱 설치
