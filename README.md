# Happy_livestock

## 축우 현장점검 앱 (`app/`)

낙농·한우비육·번식우·한우송아지 농장 점검을 스마트폰에서 입력하고 리포트까지 만드는 웹앱(PWA)입니다. 농장 탭에서 점검 분야를 여러 개 고를 수 있습니다.

- **낙농**: 퓨리나 목장점검 리포트(CCCS) 8개 섹션, 측정값 자동 판정 / 적정 건유우·갱신두수·육성우 요구두수 / 원유 체세포·세균수 등급
- **한우비육**: 비육 우군별 상태 점검표·관리 점검표 배점 / 우방별 월령·체중·급여량을 교재 표준(6~30개월)과 비교 / 출하성적
- **번식우**: 번식우 점검표 100점 / 분만율, 분만간격, 초산월령, 수태당 종부횟수
- **한우송아지**: 한우송아지 체크리스트 200점
- **개체관찰**: 우군별 BCS·체형, 보행, 반추위, 분변, 미소화분변, 청결, 유두 / CowSignals 체크포인트 / 두수 카운팅
- **리포트**: 분야별 점수, 우선순위 개선안, 카톡용 요약, CSV / **기록**: 기기 저장, 백업

점검 항목과 기준은 `app/index.html` 상단 설정(`DAIRY`, `BEEF`, `COW`, `CALF`, `STD`, `SIGNALS`, `SIGNS`)에서 바꿉니다.

### 배포
GitHub Pages(Settings → Pages → 브랜치 선택)로 올리면 `https://<계정>.github.io/Happy_livestock/app/` 에서 열리고, 휴대폰에서 "홈 화면에 추가"하면 오프라인에서도 동작합니다.
