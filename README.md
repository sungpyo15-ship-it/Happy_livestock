# Happy_livestock

## 축우 현장점검 앱 (`app/`)

낙농·한우비육·번식우·한우송아지 농장 점검을 스마트폰에서 입력하고 리포트까지 만드는 웹앱(PWA)입니다. 농장 탭에서 점검 분야를 여러 개 고를 수 있습니다.

- **낙농**
  - CCCS 착유우 사육환경 지수카드 215점 (감점 규칙 자동 계산)
  - 사양·환경 측정 (목장점검 리포트, 파워북, Walkthrough, CowSignals 워크숍)
  - 문제진단 (파워북 섭취량·연변·생산성 매뉴얼)
  - 유성분 해석 (지방/단백 비 1.05·1.35, SNF 8.3, MUN 12~18, 비유단계별 기준), 필요건물량
- **한우비육**: 한우고급육 농장 점검표 135점(우수농장 9곳 평균 비교) / 비육 우군별 상태 점검표 / 맥스 24개월 프로그램 대비 우방별 체중·급여량·사료비
- **번식우**: 번식우 점검표 100점 / **한우송아지**: 체크리스트 200점
- **개체관찰**: BCS(비유단계별 목표), 보행, 발목, 반추위, 청결, 분변, 미소화분변, 유두 / CowSignals 체크포인트 / 두수 카운팅
- **팀 사용**: 관리자(소유자) 승인제, 팀원 중지·삭제, 팀원 점검 기록 공유 (claude.ai에서 열 때)
- **리포트**: 농가 피드백 자동 작성(수정 가능)·평가자 소견, 핵심 권고 3개, 목표·후속 조치, Gmail 발송·초안(claude.ai에서 열 때), 휴대폰 공유하기·메일 앱(단독 배포 시), 보고서 파일(.html), 카톡용 요약, CSV / **기록**: 기기 저장, 백업

사용 설명서와 항목별 기준 해설은 앱 오른쪽 위 `?` 버튼, 또는 `app/manual.pdf`(인쇄용)·`app/manual.html`에서 볼 수 있습니다.

점검 항목과 기준은 `app/index.html` 상단 설정(`CCCS`, `DFEED`, `DDIAG`, `HQ`, `BEEF`, `COW`, `CALF`, `STD`, `SIGNALS`, `SIGNS`), 항목 해설은 `WHY`, `SIGWHY`)에서 바꿉니다.

### 배포 (Claude 계정 없이 링크로 쓰는 단독 배포판)
Cloudflare Pages + Cloudflare Access(50명까지 무료)로 배포해, 관리자가 허용한 이메일만 로그인(이메일 인증번호)해서 쓰게 합니다.
설정 순서는 [`docs/cloudflare_setup.md`](docs/cloudflare_setup.md)를 보세요. 빌드 출력 폴더는 `app`, 빌드 명령은 없습니다.

- Access 뒤에서 열리면 앱이 로그인 이메일을 읽어 팀 코드를 묻지 않습니다. Access 없이 배포된 경우에만 팀 코드(`TEAM_CFG.codeHash`, 기본 `HAPPY2026`)를 묻습니다.
- 저장소는 비공개로 두세요. 회사 교육자료 기반 기준이 들어 있습니다.
