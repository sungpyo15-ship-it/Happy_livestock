# Happy_livestock

## 낙농 현장점검 앱 (`app/`)

CCCS(카우컴포트 체크시트)와 카우시그널 점검을 스마트폰에서 바로 입력하고 리포트까지 만드는 웹앱(PWA)입니다.

- **농장**: 기본정보, 검정성적(지/단 비, MUN, 체세포 자동 판정), 온습도 → THI 자동 계산
- **CCCS**: 8개 섹션 35개 항목, 양호/주의/불량/해당없음 → 섹션·종합 점수와 등급
- **카우시그널**: 우군별(건유·분만전후·비유초기·중후기) 보행·반추위 충만도·분변·BCS·비절·청결도·유두끝 탭 집계, CCI·반추비율 계산
- **리포트**: 우선순위별 개선안 자동 생성, 카톡용 요약 복사, CSV(엑셀) 저장
- **기록**: 기기 내 저장, JSON 백업/복원

점검 항목과 판정 기준은 `app/index.html` 상단의 `CCCS`, `SIGNALS` 설정만 고치면 바뀝니다.

### 배포
GitHub Pages(Settings → Pages → 브랜치 선택)로 올리면 `https://<계정>.github.io/Happy_livestock/app/` 에서 열리고, 휴대폰에서 "홈 화면에 추가"하면 오프라인에서도 동작합니다.
