# Happy_livestock

## 낙농 현장점검 앱 (`app/`)

CCCS(카우컴포트 체크시트)와 카우시그널 점검을 스마트폰에서 바로 입력하고 리포트까지 만드는 웹앱(PWA)입니다.

- **농장**: 사육두수·번식·생산성 입력 → 적정 건유우, 갱신두수, 육성우 요구두수, 두당 산유량, 체세포 손실량 자동 계산 / THI
- **목장점검(CCCS)**: 퓨리나 목장점검 리포트 기준 8개 섹션(환경, 휴식공간·우상, 급수조, 사조, TMR·배합비·조사료, 건유우, 착유장, 건강·번식). 측정값 입력 시 자동 판정
- **카우시그널**: 초산우·비유초기·착유우·건유우별 BCS, 보행, 발목, 반추위 충만도, 청결, 분변, 미소화분변, 유두, 발굽지수 집계 / 호흡수·배뇨·반추 저작 / CowSignals 건강·복지 체크포인트 20종 / 소 상태 두수 카운팅
- **송아지**: 퓨리나 한우송아지 체크리스트 200점
- **리포트**: 우선순위별 개선안 자동 생성, 카톡용 요약 복사, CSV(엑셀) 저장
- **기록**: 기기 내 저장, JSON 백업/복원

점검 항목과 판정 기준은 `app/index.html` 상단의 `CCCS`, `SIGNALS`, `SIGNS`, `CALF` 설정만 고치면 바뀝니다.

### 배포
GitHub Pages(Settings → Pages → 브랜치 선택)로 올리면 `https://<계정>.github.io/Happy_livestock/app/` 에서 열리고, 휴대폰에서 "홈 화면에 추가"하면 오프라인에서도 동작합니다.
