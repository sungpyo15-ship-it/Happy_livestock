smaXtec 목장 모니터 · Windows

팀원 설치 안내

본인 smaXtec 계정으로 설치하면 본인 담당 목장만 보입니다. 다른 사람의 아이디·비밀번호는 쓰지 않습니다. 설치는 30분 정도 걸립니다.

준비물

  • Windows PC매일 06:00에 켜져 있거나 절전 상태인 PC (노트북은 충전기 연결)
  • 본인 smaXtec 계정web.smaxtec.com 에 로그인되는지 먼저 확인
  • 프로그램 ZIP담당자에게 받은 smaxtec_monitor_latest.zip
  • (휴대폰 앱) Tailscale 계정구글 계정으로 가입 가능 · 개인 사용 무료

PC 설치

  1. Python 설치 (처음 한 번)

    • python.org/downloads 에서 최신 버전 내려받기 → 설치
    • 설치 첫 화면 아래 "Add python.exe to PATH" 를 꼭 체크

  2. 압축 풀기

    • ZIP 을 오른쪽 클릭 → 모두 압축 풀기
    • 안에 있는 smaxtec_monitor 폴더를 찾기 쉬운 곳(예: 문서)으로 옮기기

  3. 1_INSTALL.bat 더블클릭

    • "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행
    • 메모장이 열리면 SMX_USERNAME= 뒤에 본인 아이디, SMX_PASSWORD= 뒤에 비밀번호 → Ctrl+S 저장 → 메모장 닫기
    • 창에 "로그인 성공"과 본인 목장 목록이 나오면 완료

  4. 2_RUN_REPORT.bat 더블클릭

    • 첫 실행은 과거 150일 기록을 받느라 10분 정도 걸립니다 (한 번만)
    • 끝나면 reports 폴더가 열리고 일일 리포트·방문요약·앱 파일이 생깁니다

  5. 3_AUTO_6AM.bat 더블클릭

    • 매일 06:00 자동 수집·리포트, 낮 동안 2시간마다 수집
    • PC 를 끄지 말고 절전으로 두세요. 노트북은 밤에 충전기를 꽂아 두세요

  6. 5_OPEN_APP.bat 으로 PC 에서 앱 열기

    요약표 · 목장별 · 7일추세 · 전환기 · 투입비교 · 그룹행동 · 집단신호

휴대폰 앱 (선택)

  1. PC 에 Tailscale 설치·로그인

    tailscale.com/download 에서 Windows 용 설치 → 본인 구글 계정 등으로 로그인

  2. 7_IPHONE_SETUP.bat 더블클릭

    • 앱 서버 자동 시작이 등록되고 https://○○○.ts.net 주소가 나옵니다 → 메모
    • "HTTPS 허용" 링크가 나오면 열어서 Enable HTTPS 누른 뒤 다시 실행

  3. 휴대폰에 Tailscale 설치

    App Store / Play 스토어에서 Tailscale 설치 → PC 와 같은 계정으로 로그인 → 연결 켜기

  4. 주소 열고 홈 화면에 추가

    아이폰

    Safari 로 주소 열기 → 아래 공유 버튼 → 홈 화면에 추가

    안드로이드

    Chrome 으로 주소 열기 → 오른쪽 위 ⋮ → 홈 화면에 추가 (또는 앱 설치)

    주소가 길면 카카오톡 '나와의 채팅'으로 보내 복사해 붙여넣으세요.

새 버전 받았을 때

  • 1. 압축 풀기새 ZIP 을 새 폴더에 풀기
  • 2. 내 파일 옮기기기존 폴더의 .env 와 투입기록.xlsx 를 새 폴더로 복사 (.env 가 안 보이면 탐색기 보기 → 숨긴 항목)
  • 3. 다시 등록3_AUTO_6AM.bat, 휴대폰 앱을 쓰면 7_IPHONE_SETUP.bat
꼭 지켜 주세요

· 아이디·비밀번호는 본인 것만, 본인 PC 의 .env 에만 저장. .env 파일은 다른 사람에게 보내지 마세요.

· 리포트·앱의 목장 데이터는 농장주 소유입니다. 다른 목장·외부 업체·SNS 에 공유하지 마세요.

· 판정(집단신호·전환기·투입비교)은 센서 알림 기반 선별 자료이며 진단이 아닙니다.

알아두면 좋은 점

· "담당 목장 중앙값" 같은 비교 기준은 본인 담당 목장 안에서 계산됩니다. 담당 목장이 적으면(전환기는 분만 8두 이상 목장 3곳 미만) 일부 비교가 표시되지 않습니다.

· 오류가 나면 검은 창 화면을 캡처해 담당자에게 보내 주세요. 비밀번호가 보이면 가려 주세요.
