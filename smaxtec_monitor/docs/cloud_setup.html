무료 서버 설치 안내

Google Cloud 평생 무료 서버(e2-micro)에 설치하면 PC 없이 24시간 수집되고, 팀원은 링크 → smaXtec 로그인 → 홈 화면 추가만 하면 됩니다. 처음 한 번 1시간 정도 걸립니다.

준비물

  • 구글 계정Google Cloud 와 무료 주소(DuckDNS) 가입에 사용
  • 해외결제 카드본인확인용. 무료 범위에서는 청구 없음
  • PC 또는 휴대폰 브라우저서버 접속도 브라우저에서 합니다
  • 본인 smaXtec 아이디관리자 계정으로 등록

설치 순서

  1. Google Cloud 가입 10분

    • cloud.google.com/free → 무료로 시작하기 → 구글 계정으로 로그인
    • 국가 대한민국, 계정 유형 개인, 카드 등록 → 90일 무료 체험 크레딧이 생깁니다 (자동 결제되지 않음)

  2. 서버 만들기 10분

    • 콘솔 왼쪽 메뉴 → Compute Engine → VM 인스턴스 (처음이면 "사용 설정" 누르고 1~2분 대기) → 인스턴스 만들기
    • 화면 왼쪽의 단계 메뉴를 위에서부터 차례로 설정합니다 (안 보이면 창을 크게 하거나 아래로 스크롤)
    • 머신 구성: 이름 smxmon · 리전 us-west1 (오리건) · 시리즈 E2 · 머신 유형 e2-micro
    • OS 및 스토리지 (OS and storage) → [변경] → 운영체제 Ubuntu, 버전 Ubuntu 24.04 LTS (x86/64), 부팅 디스크 유형 표준 영구 디스크(Standard), 크기 30 GB → [선택]
    • 네트워킹: HTTP 트래픽 허용, HTTPS 트래픽 허용 둘 다 체크
    • 나머지 메뉴(데이터 보호·관찰 가능성·보안·고급)는 그대로
    • 만들기 → 목록에 생긴 서버의 외부 IP 를 메모 (예: 34.82.xx.xx)

    오른쪽 예상 비용에 월 요금이 보여도 정상입니다. 무료 등급(e2-micro 1대·표준 디스크 30GB·미국 3개 리전)은 청구서에서 0원으로 처리됩니다.

  3. 요금 알림 걸기 2분

    • 왼쪽 메뉴 → 결제 → 예산 및 알림 → 예산 만들기 → 금액 1,000원 → 메일 알림
    • 실수로 유료 항목이 생기면 바로 메일이 옵니다

  4. 무료 주소 만들기 (DuckDNS) 3분

    • duckdns.org → 구글로 로그인
    • sub domain 에 원하는 이름(예: mokjang-monitor) → add domain
    • current ip 칸에 2번의 외부 IP 입력 → update ip
    • 화면 위쪽 token 값을 복사해 두기 (6번에서 사용 — 서버 IP 가 바뀌어도 주소가 자동으로 따라감)

  5. 서버 접속 1분

    • VM 인스턴스 목록에서 서버 줄의 SSH 버튼 클릭 → 새 창에서 "승인"
    • 검은 화면에 ...@smxmon:~$ 가 보이면 접속된 상태입니다

  6. 설치 명령 붙여넣기 10분

    SSH 창에 아래 두 줄을 붙여넣습니다(붙여넣기: Ctrl+V 또는 마우스 오른쪽). 주소·아이디·토큰은 본인 것으로 바꾸세요. 관리자 아이디는 smaXtec 로그인 아이디입니다.

    curl -fsSL https://raw.githubusercontent.com/sungpyo15-ship-it/Happy_livestock/refs/heads/claude/practical-cori-rbbhxw/smaxtec_monitor/deploy/install.sh -o install.sh
sudo bash install.sh 내주소.duckdns.org smaXtec아이디@이메일 DuckDNS토큰

    마지막에 "설치 완료" 와 주소가 나오면 끝입니다. 오류가 나면 창 내용을 캡처해 보내 주세요.

  7. 휴대폰에서 열기 10분

    • 휴대폰에서 https://내주소.duckdns.org 열기 → smaXtec 아이디·비밀번호로 로그인
    • 처음에는 지난 1년 기록을 가져오느라 15~30분 "데이터 준비 중" 화면이 나옵니다
    • 아이폰은 Safari 공유 → 홈 화면에 추가, 안드로이드는 Chrome ⋮ → 홈 화면에 추가

  8. 팀원 등록

    • 앱 오른쪽 위 계정 → 아래 관리자 — 팀원 등록에 팀원의 smaXtec 아이디 입력 → 등록
    • 팀원에게 주소만 보내면 됩니다. 팀원은 본인 아이디로 로그인하고 본인 담당 목장만 봅니다

서버 통째로 백업 — 스냅샷 일정 (한 번만 설정, 5분)

자동 백업은 같은 서버 디스크에 저장됩니다. 서버가 삭제·고장 나는 경우까지 대비하려면 Google Cloud 의 디스크 스냅샷을 매일 찍어 둡니다.

  1. 만들기: Google Cloud 콘솔 → Compute Engine → 스냅샷 → 위쪽 스냅샷 일정 탭 → 스냅샷 일정 만들기
    • 이름 smxmon-daily · 리전 us-west1 · 스냅샷 위치 리전 (us-west1)
    • 일정 빈도 매일 · 시작 시간 20:00~21:00 (UTC) = 한국 05:00~06:00 (04:40 자동 백업 직후)
    • 자동 삭제 7일 후 → 만들기
  2. 디스크에 연결: Compute Engine → 디스크 → smxmon 디스크 → 위쪽 수정 → 스냅샷 일정에서 smxmon-daily 선택 → 저장
  3. 확인: 다음 날 Compute Engine → 스냅샷에 스냅샷이 생겼는지 보기

요금: 스냅샷은 바뀐 부분만 저장합니다. 무료 등급에 일부 스냅샷 용량이 포함되는 것으로 알려져 있으나 지역·시점별 조건은 결제 화면에서 확인 필요. 넘어도 사용 데이터 수 GB 기준 월 수백 원 수준(GB당 월 약 0.05달러, 추정). 3번에서 건 요금 알림으로 확인됩니다.

서버가 망가졌을 때: Compute Engine → 스냅샷 → 날짜 고르기 → 인스턴스 만들기(같은 e2-micro·표준 디스크·us-west1). 외부 IP가 바뀌면 DuckDNS 가 자동으로 새 주소를 잡습니다(몇 분).

꼭 확인할 것

· 부팅 디스크는 반드시 표준 영구 디스크. 기본값(균형)은 유료입니다. 서버는 e2-micro 1대만 무료입니다.

· 데이터는 미국(오리건) 서버에 저장됩니다. 팀원 등록 전에 리얼팜에 "팀원 계정으로 서버가 자동 조회하는 방식"과 함께 확인하세요.

· 팀원에게 알려 주세요: 비밀번호는 암호화해 서버에 보관하며, 서버 관리자는 기술적으로 접근할 수 있습니다. 앱의 [연결 해제]로 언제든 삭제됩니다.

· DuckDNS 토큰과 Google Cloud 계정은 남에게 알려 주지 마세요.

PC 버전(지금 쓰는 프로그램)은 그대로 계속 쓸 수 있습니다. 클라우드가 안정되면 PC 쪽 06시 자동 실행은 꺼도 됩니다.
