목장 모니터 사용 설명서

시작하기

1. 등록 요청관리자에게 본인 smaXtec 아이디(이메일)를 알려 주고 등록을 받습니다.
2. 로그인관리자가 보낸 앱 주소를 열고 smaXtec 아이디·비밀번호로 로그인합니다.
3. 첫 준비처음에는 담당 목장의 1년치 기록을 받느라 15~30분 걸립니다. 화면이 알아서 바뀝니다.

휴대폰 홈 화면에 추가 (앱처럼 쓰기)

  • 아이폰: Safari 로 주소 열기 → 아래 공유 버튼 → 홈 화면에 추가
  • 안드로이드: Chrome 으로 주소 열기 → 오른쪽 위 ⋮ → 홈 화면에 추가
  • PC: 같은 주소를 브라우저 즐겨찾기에 넣으면 됩니다.

언제 새 자료가 들어오나

  • 자동: 매일 06:30(07시 전 판정 확정), 12:30, 18:30 하루 3번(관리자가 4시간·2시간 간격으로 바꿀 수 있음, 계정 화면에 지금 설정 표시). 밤에는 쉬고 다음 날 아침에 한꺼번에 들어옵니다.
  • 바로 보고 싶으면 오른쪽 위 계정 → 지금 새로고침 (20분에 한 번). 몇 분 뒤 반영됩니다.
  • smaXtec 앱의 푸시 알림은 실시간이고, 이 앱은 추세·목장 비교·방문 계획용입니다. 급한 개체는 smaXtec 앱을 그대로 보세요.

하루 사용 흐름

  1. 아침: 오늘 할 일 보기
    앱을 열면 첫 화면이 오늘 할 일입니다. 오늘 가볼 목장 3곳과 이유, 볼 개체, 할 조치 하나가 나옵니다.
  2. 방문 전: 목장 상세 확인
    목장 상세 › 를 눌러 7일 추세·그룹 행동·전환기 성적·조치 가이드를 봅니다. 엑셀 방문요약 1장을 뽑아 가도 됩니다.
  3. 목장에서: 점검·조치
    목장 상세 7. 조치 가이드(확인 → 바로 할 조치 → 수의사 연락 기준)와 8. 현장 점검 체크리스트를 보며 확인합니다.
  4. 방문 후: 조치 기록
    조치 기록하기 → 대상·신호·한 조치를 버튼으로 고르고 저장합니다. 1분이면 됩니다.
  5. 7일 뒤: 결과 입력
    첫 화면 결과 입력 대기에 뜬 기록에 회복·치료·도태 또는 개선·변화 없음·악화를 누릅니다.

두수 기준
같은 소가 여러 번 울려도 1두로 셉니다. smaXtec 앱의 알림 '건수'보다 숫자가 작을 수 있습니다.
급증
오늘 건강알림 두수가 전날 또는 7일 평균의 2배 이상이고, 2두 이상 늘었을 때.
집단신호
몇 시간 안에 여러 마리가 체온 상승·반추 감소를 함께 보일 때. 사료 변경, 더위, 전염성 질병 같은 공통 원인을 의심합니다.

용어 풀이

100두당
알림 두수 ÷ 센서 단 두수 × 100. 목장 크기가 달라도 비교할 수 있게 맞춘 값.
7일평균
직전 7일 각각의 하루 두수 평균. 오늘이 평소보다 많은지 보는 기준.
누운 시간
하루 중 누워 쉰 시간. 착유우 9시간 미만이면 누울 자리·과밀·더위·해충을 점검.
누워반추
되새김 가운데 누워서 한 비율. 높을수록 편안한 상태.
함께 눕기
같은 시간에 그룹 소들이 함께 누워 있는 비율. 떨어지면 누울 자리 경쟁·과밀·더위·침파리를 의심.
Δ (델타)
7일 평균 대비 변화. Δ반추 −40 = 평소보다 하루 40분 적게 되새김.
무사통과
분만 후 21일 동안 건강알림이 한 번도 없었던 소의 비율. 전환기 사양의 성적표.
발생률(전환기)
분만 후 21일 안에 그 알림이 한 번이라도 나온 두수 ÷ 분만 두수. 센서 '의심' 기준이라 진단 발생률과 다름.
F/P
검정성적의 유지방 ÷ 유단백. 분만 60일 안에 1.5 초과 = 케토시스 위험, 1.0 미만 = 산독증 위험 지표(참고 기준).
[문헌] / [관행]
조치 가이드의 수치 표시. [문헌]은 논문·공식 지침에 근거한 기준, [관행]은 현장에서 널리 쓰는 경험 기준이라 목장마다 조정합니다. 가이드 문구는 관리자가 엑셀로 고쳐 팀 전체에 반영합니다.
알림 지속
판정 뒤 7일 동안 알림이 그 목장 평소보다 높게 이어졌는지(평소 = 1.0). 판정 검증에서 씁니다.

조치·결과 기록

현장에서 한 일과 그 결과를 버튼으로 남기는 칸입니다. 쌓이면 "이 조치를 하면 알림이 얼마나 줄었나"를 보여 주는 컨설팅 성과 자료가 됩니다.

  1. 들어가기: 첫 화면 조치 기록하기, 또는 목장 상세 맨 아래 9. 담당자·조치·결과 기록
  2. 대상: 목장 전체 / 그룹 / 개체 중 하나. 목록에 없는 소는 다른 개체번호 칸에 적기
  3. 관련 신호: 지금 그 목장에 걸린 신호가 버튼으로 나옵니다. 정기 방문이면 정기 점검
  4. 한 조치(여러 개 가능): 사료 배합 조정, 급여·TMR 관리, 첨가제 투입, 우사 환경 개선, 해충 방제, 수의사 진료 의뢰 등
  5. 날짜·내용을 적고 저장. 예) "조사료 볏짚→티모시 2kg", "끈끈이 트랩 20개"
  6. 7일 뒤 결과: 개체는 회복 / 치료 후 회복 / 치료 중 / 도태 / 변화 없음, 목장·그룹은 개선 / 변화 없음 / 악화

휴대폰과 PC에 함께 저장됩니다. 잘못 넣은 기록은 오른쪽 × 로 지웁니다. 모아 보기: 계정 → 조치 기록(엑셀) — 조치별 결과와 조치 전후 건강알림 변화가 자동 계산됩니다(대조군 없는 전후 비교라 여러 건의 경향으로 판단).

담당자 업무지시 문자

긴급·우선 목장을 맡은 딜러·판매과장에게 사유·확인 개체·요청 조치가 담긴 문자를 보냅니다. 한 담당자가 여러 목장을 맡으면 문자 한 통으로 묶입니다.

  1. 담당자 등록: 목장 상세 9번 맨 위 담당자 등록 → 구분(딜러·판매과장 등)·이름·휴대폰 → 저장. 관리자는 계정 → 목장 담당자에서 엑셀로 한 번에 넣을 수 있습니다.
  2. 보내기: 첫 화면 업무지시 보내기에서 담당자별 카드의 문자 보내기. 휴대폰 문자 앱이 받는 사람·내용이 채워진 채 열리고, 확인 후 직접 전송합니다. PC에서는 카카오톡용 복사.
  3. 내용 고치기: 보낼 내용 보기·고치기를 펼쳐 문구를 고친 뒤 보내면 고친 내용으로 나갑니다.
  4. 결과 확인: 보낸 지시는 각 목장 조치 기록에 '업무지시'로 남습니다. 7일 뒤 완료 보고 / 진행 중 / 미이행을 누릅니다.

문자에는 목장 건강 정보가 들어갑니다. 그 목장 담당자에게만 보내고, 단체 대화방에는 올리지 마세요. 연락처는 팀 공용 서버에 저장되고 그 목장을 담당하는 팀원에게만 보입니다.

08:00 · 14:00팀원내 담당 목장의 '오늘 할 일' 요약(긴급 N · 우선 N)
  1. 팀원: 홈 화면에 추가한 앱 → 계정 → 이 기기에서 알림 받기 → 알림 허용 → 시험 알림 보내기로 확인
  2. 담당자: 관리자가 만든 전용 링크를 문자·카톡으로 받음 → 열어서 홈 화면에 추가 → '업무요청' 아이콘으로 열기 → 이 휴대폰에서 알림 받기. 알림을 누르면 요청 내용이 열리고 목장마다 완료 보고를 누르면 팀원 조치 기록에 바로 반영됩니다.
  3. 관리자: 계정 → 자동 업무지시 알림에서 켜기·시험 모드(모든 알림을 관리자 기기로만), 담당자별 링크 만들기·끊기, 최근 발송·전달 현황

아이폰은 iOS 16.4 이상이고 홈 화면에 추가한 앱에서만 알림을 받습니다(안드로이드는 크롬). 알림 설정을 하지 않은 담당자는 지금처럼 '업무지시 문자'로 직접 보냅니다. 담당자 링크는 비밀번호와 같으니 본인에게만 보내세요.

검정성적 올리기

  1. 검정 기관이나 목장 프로그램에서 받은 검정성적 엑셀(.xlsx)을 준비합니다. .xls 파일은 엑셀에서 .xlsx 로 다시 저장하세요.
  2. 계정 → 검정성적 올리기 → 목장 선택 → 파일 선택 → 올리기. 파일에 검정일이 없으면 날짜 칸에 넣습니다.
  3. 올린 뒤 나오는 메시지에서 저장 두수 · 센서 개체와 연결된 두수 · 못 찾은 열을 확인합니다. 연결이 너무 적으면 관리번호·이표 열 이름을 확인하세요.
  4. 갱신이 끝나면 목장 상세 4-3. 검정성적·경제성에 최근 6회 검정이 나옵니다.

4-3에서 보는 것

  • 평균 유량·유지방·유단백, F/P, 체세포·체세포 20만 이상 비율, MUN
  • 알림 소 유량 차이: 검정 전 30일 안에 건강알림이 있던 소와 없던 소를 같은 비유 시기끼리 비교
  • 월 손실 추정(만원): 유량 차이 × 두수 × 30일 × 원유 단가(기본 1,100원/kg 가정)

원래 유량이 낮은 소가 알림도 많을 수 있어 연관 관계이지 원인이라고 단정할 수 없습니다. 농장주에게 설명할 때 "추정"이라고 말해 주세요.

사료·첨가제 투입비교

  1. 계정 → 투입기록 양식/현재 파일 받기
  2. 한 줄에 투입 한 건: 목장(이름 일부), 시작일, 제품·변경 내용, 구분, 대상그룹(비우면 착유우), 비교기간(기본 21일), 적응기간(기본 7일)
  3. 저장한 파일을 올리기. 다음 갱신 때 투입비교 탭에 결과가 나옵니다.
비교 방법
투입 전 N일 vs 투입 후 N일(적응기간 제외). 같은 시기 다른 목장 변화로 계절 영향을 빼서 봅니다.
개선(유의)
통계적으로 분명한 개선(p<0.05).
개선 경향
개선 쪽이지만 아직 확실하지 않음(p<0.2). 기간을 더 두고 봅니다.

문제 해결

로그인하면 '등록 안 됨'이 나와요

관리자가 아직 등록하지 않았거나 아이디 철자가 다릅니다. smaXtec 로그인에 쓰는 이메일 그대로 관리자에게 보내 주세요.

'비밀번호 거절'이 나와요

smaXtec 이 비밀번호를 거절한 경우입니다. web.smaxtec.com 에 같은 아이디로 로그인되는지 먼저 확인하세요. 웹은 되는데 앱만 안 되면 관리자에게 알려 주세요.

'데이터 준비 중'에서 넘어가지 않아요

처음에는 1년치 기록을 받느라 15~30분 걸립니다. 1시간이 넘으면 관리자에게 알려 주세요.

화면이 예전 그대로예요

휴대폰 앱은 완전히 닫았다가 다시 열고, PC는 Ctrl+F5. 그래도 같으면 계정 → 지금 새로고침.

smaXtec 앱과 숫자가 달라요

이 앱은 같은 소의 반복 알림을 1두로 세고, '최근 24시간'을 앱 갱신 시각 기준으로 자릅니다. 개체별 원본은 목장 상세 6. 최근 24시간 알림에서 확인할 수 있습니다.

담당 목장이 안 보여요

smaXtec 에서 내 계정에 그 목장 조회 권한이 있어야 보입니다. smaXtec 웹에서 목장이 보이는지 확인하고, 권한이 생긴 뒤 지금 새로고침을 누르세요.

메모·체크·조치 기록이 다른 기기에 안 보여요

인터넷이 끊긴 상태에서 입력하면 그 기기에만 남을 수 있습니다. 연결된 상태에서 앱을 다시 열면 서버로 올라갑니다. 메모 아래 '모든 기기에 저장됨'이 보이면 저장된 것입니다.

그만 쓰고 싶어요

계정 → 연결 해제. 서버에 저장된 비밀번호와 수집 자료가 모두 지워집니다.

꼭 지킬 것

진단 도구가 아닙니다

센서 알림은 '의심 신호'입니다. 약품 사용과 치료는 반드시 수의사 진료·처방에 따르고, 앱의 조치 가이드에는 약품명·용량을 넣지 않았습니다.

목장 자료는 농장주 것입니다

화면 캡처·엑셀을 다른 목장, 다른 회사, 단체 대화방, SNS 에 올리지 마세요. 자료를 쓸 때는 목장 이름을 가립니다.
