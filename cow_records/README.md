# 개체 기록부 (cow_records) — 데모

smaXtec 에 기록된 번식 이벤트와 메모로 **목장별 번식기록지**와 **개체별 질병·치료 기록**을 자동 정리.
우선 관리자(성표) 데모용. smaXtec 로그인·이벤트 수집은 같은 저장소의 `smaxtec_monitor`(smxmon)를 재사용.

## 쓰는 데이터 (smaXtec 공식 API, 읽기 전용)
| 데이터 | 출처 | 용도 |
|---|---|---|
| 분만확인(산차)·분만감지·발정·수정·임신감정(결과·분만예정일)·건유·유산 | integration `/organisations/{id}/events` (smxmon 이 수집·저장) | 번식기록지 |
| 개체(관리번호·이표·그룹·비유상태) | integration `/organisations/{id}/animals` (smxmon) | 표시 |
| **smaXtec 메모** — 분류(UDDER·METABOLISM…)·질병(MASTITIS·KETOSIS…)·조치·메모 | public `/organisations/{id}/todos` 의 `note_id` → `/notes/{id}` | 질병·치료 기록 |
| 알림 확인 코멘트(자유 텍스트) | public `/organisations/{id}/todos` 의 `comments` | 질병·치료 기록 |
| 진단 이벤트, 센서 임상 알림(케토시스·유방염·유열 의심) | smxmon DB | 질병·치료 기록 |

### 실측으로 확인한 한계 (2026-11)
- 메모는 **알림 확인 기록에 연결된 것만** 목록으로 얻을 수 있음(공개 API 에 메모 목록 없음) → 알림과 무관한 메모는 누락 가능
- 메모를 쓰는 목장도 대부분 **질병명만** 입력, 조치(약품) 칸은 거의 비어 있음 → 치료 내역은 현재 '질병 발생 기록' 수준
- 정액(종모우)·약품명·휴약기간은 smaXtec 에 없음 → 엑셀에 수기 입력 칸 제공
- 수집 이력(약 410일) 이전 분만은 분만일 미확인

## 결과물
- `reports/개체기록부_<목장>_<날짜>.xlsx` — **번식기록지**(개체별: 산차·분만일·착유일수·첫 발정·수정 1~4+·감정·수태일·공태일수·분만예정·건유예정·상태·주의·정액/메모 수기 칸), **번식성적**(임신우 비율·평균 공태일수·첫 수정·수태당 수정 횟수·분만간격·주의 개체), **질병기록**
- `reports/개체기록부.html` — 앱: 목장 목록(메모 쓰는 목장 표시) → 목장 번식 현황(상태 필터) → 개체 상세(이번 산차 번식, 질병·치료 기록, 번식 이벤트 이력)

## 상태 판정
신선(분만 21일 이내·수정 전) / 공태(수정 전) / 수정 후 감정 전 / 재수정 필요(감정 음성) / 임신 / 건유 / 미경산·분만 미확인
주의: 분만 150일 이상 미임신, 수정 3회 이상 미임신, 분만 60일 이상 발정 없음, 수정 45일 지나 감정 필요, 분만예정 30일 이내, 건유 시기
한우(목장명에 '한우'·'비육')는 임신기간 285일, 건유 없음

## 명령
```
python -m cowrec demo                       # 가상 데이터
python -m cowrec collect [목장...] --events  # 이벤트(smxmon) + 메모 수집
python -m cowrec build [목장...] --memo-only # 엑셀 + 앱
python -m pytest -q tests
```
로그인 정보는 `smaxtec_monitor/.env` 를 사용. `data/`, `reports/` 는 저장소에 올리지 않음(목장 데이터).
