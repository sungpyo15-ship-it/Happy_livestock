# 공룡 친구 여행

아들과 함께 만드는 스마트폰 게임입니다. 공룡을 키우고, 여행하며 코인을 모으고, 반짝이는 알을 찾아 친구를 깨웁니다.

## 게임 방법
- **돌보기(다마고치)**: 배부름, 기분, 기운, 깨끗함 4가지가 실제 시간에 따라 줄어들어요. 앱을 꺼 둬도 줄어요(최대 12시간치).
  - 🍖 먹이: 풀잎(공짜), 고기(10코인), 케이크(30코인). 좋은 먹이일수록 쑥쑥 자라요.
  - ⚽ 놀기: 공을 던지면 공룡이 물어 와요. 공룡을 손가락으로 문지르면 쓰다듬기가 돼요.
  - 🛁 씻기: 샤워로 깨끗하게. 바닥의 응가는 눌러서 하나씩 치울 수도 있어요.
  - 📺 TV: 공룡 만화, 별 쇼, 물고기 채널. TV를 누르면 채널이 바뀌어요. 한 시간에 3번까지만 볼 수 있어요(아드님 아이디어).
  - 🌙 재우기: 자는 동안 기운이 차요. 화면을 켜 두면 1분에 36씩, 꺼 두면 1시간에 25씩.
  - 너무 오래 돌보지 않으면 아파요. 약을 주면 나아요. 아프거나 배고프거나 졸리면 여행을 못 가요.
- **드래곤(아드님 아이디어)**: Lv.6 전설의 공룡이 되면 드래곤으로 변신해요. 날개와 뿔이 생기고, 누르면 불을 뿜고, 여행에서 점프를 한 번 더 할 수 있어요.
  때가 되면 "날려 보내기"로 하늘 나라에 보내요. 코인 100개와 새 알을 남기고, 친구 둥지의 "드래곤 하늘"에 기록되고, 가끔 집 하늘로 놀러 와요.
- **집**: 공룡을 톡 누르면 점프하고 지금 필요한 것을 말해요.
- **여행**: 화면을 누르면 점프, 공중에서 한 번 더 누르면 더 높이 뛰어요. 하트를 다 잃으면 여행이 끝나요.
- **친구 둥지**: 여행 중 찾은 알을 코인으로 깨워요. 친구를 여행 짝꿍으로 데려가면 특별한 능력을 써요.
- **레벨**: Lv.2 모래 사막, Lv.3 눈꽃 산, Lv.5 불꽃 화산이 열려요. Lv.4가 되면 하트가 1개 늘어요.

## 아들과 같이 바꿔 보기 좋은 곳 (`index.html`)
| 바꾸고 싶은 것 | 찾을 단어 |
|---|---|
| 친구 이름, 능력, 깨우는 코인 | `const FRIENDS` |
| 여행지 이름, 색, 속도, 장애물 | `const ZONES` |
| 공룡이 하는 말 | `const TALK`, `function needLine` |
| 먹이 종류와 가격 | `const FOODS` |
| 배고파지는 속도 | `const RATES` |
| 공룡 색 | `const COLORS` |
| 점프 높이 | `JUMP1`, `JUMP2` |

## 폰에 앱처럼 설치하기
1. 이 폴더를 인터넷 주소로 열 수 있게 올립니다(예: GitHub Pages).
2. 폰에서 주소를 엽니다.
   - 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
   - 안드로이드(Chrome): 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**
3. 홈 화면 아이콘으로 실행하면 앱처럼 전체 화면으로 열리고, 인터넷이 없어도 열립니다.

진행 상황(코인, 친구)은 그 폰의 브라우저에 저장됩니다.
게임 파일을 고친 뒤에는 `sw.js`의 `VERSION` 숫자를 올려야 폰에 새 버전이 반영됩니다.
