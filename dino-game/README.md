# 공룡 친구 여행

아들과 함께 만드는 스마트폰 게임입니다. 공룡을 키우고, 여행하며 코인을 모으고, 반짝이는 알을 찾아 친구를 깨웁니다.

## 게임 방법
- **집**: 공룡을 누르면 점프하고 말을 해요. 코인 10개로 먹이를 주면 경험치가 올라요.
- **여행**: 화면을 누르면 점프, 공중에서 한 번 더 누르면 더 높이 뛰어요. 하트를 다 잃으면 여행이 끝나요.
- **친구 둥지**: 여행 중 찾은 알을 코인으로 깨워요. 친구를 여행 짝꿍으로 데려가면 특별한 능력을 써요.
- **레벨**: Lv.2 모래 사막, Lv.3 눈꽃 산, Lv.5 불꽃 화산이 열려요. Lv.4가 되면 하트가 1개 늘어요.

## 아들과 같이 바꿔 보기 좋은 곳 (`index.html`)
| 바꾸고 싶은 것 | 찾을 단어 |
|---|---|
| 친구 이름, 능력, 깨우는 코인 | `const FRIENDS` |
| 여행지 이름, 색, 속도, 장애물 | `const ZONES` |
| 공룡이 하는 말 | `const TALK` |
| 공룡 색 | `const COLORS` |
| 점프 높이 | `JUMP1`, `JUMP2` |

## 폰에 앱처럼 설치하기
1. 이 폴더를 인터넷 주소로 열 수 있게 올립니다(예: GitHub Pages).
2. 폰에서 주소를 엽니다.
   - 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
   - 안드로이드(Chrome): 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**
3. 홈 화면 아이콘으로 실행하면 앱처럼 전체 화면으로 열리고, 인터넷이 없어도 열립니다.

진행 상황(코인, 친구)은 그 폰의 브라우저에 저장됩니다.
게임 파일을 고친 뒤에는 `sw.js`의 `VERSION` 숫자를 올려야 폰에 새 버전이 반영됩니다.
